# AI Experiments

This repository contains a collection of small AI-related projects, experiments, and learning exercises.

The goal of this repo is to explore different concepts, tools, models, and workflows in AI development while building practical hands-on projects.

## Structure

Each project lives in its own subfolder.

Example structure:

```text
.
├── brochure/
│   ├── main.py
│   └── README.md
├── another-project/
│   ├── ...
│   └── ...
└── README.md
```

## Purpose

This repository is mainly for:

- Learning AI development
- Experimenting with LLM workflows
- Trying different tools and approaches
- Building small practical AI applications

## Notes

Projects in this repository may:

- Change frequently
- Be incomplete or experimental
- Use different frameworks, models, or architectures
- Prioritize learning and exploration over production readiness
